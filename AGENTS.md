# AGENTS.md

This repo is an agent harness. Before doing anything else:

1. Read `steering/00-session-opener.md` and follow its read order.
2. Read `handoffs/NEXT_AGENT_HANDOFF.md`. It says where the last session stopped.
3. Read the active spec it names under `.kiro/specs/`.
4. Load a skill from `skills/` before the work it governs. The routing table is `skills/README.md`.
5. Real project data never enters this IDE. See `steering/40-data-boundary.md`.

If Kiro loaded `.kiro/steering/`, you have already read the steering files. This file exists for
tools that read `AGENTS.md` and nothing else.
